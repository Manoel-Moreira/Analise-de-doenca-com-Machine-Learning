# Analise-de-doenca-com-Machine-Learning
Projeto de para Análise de Doença utilizando uma base de dados para treinamento 

* Os dados para o treinamento já estavam prontos (ETL)
* Primeiro passo foi vetorizar esses dados, para isso foi utilizado o TfidfVectorizer da biblioteca TfidfVectorizer
* Depois foi feito o treinamento do modelo usando o XGBClassifier da biblioteca XGBoost
